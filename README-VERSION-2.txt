UPDATED WEBSITE — VERSION 2

Purpose
-------
This package contains the same website content as Updated Website — Version 1,
but uses the visual design inspired by the supplied screenshot:
- pale blue-green / off-white background
- Source Serif 4 display typography
- DM Sans body typography
- deep teal accents
- editorial spacing and thin rules
- a dark-teal featured research treatment
- dark professional footer

Recommended setup
-----------------
1. Keep Version 1 on the `main` branch.
2. Create a new branch from main named:
   updated-website-version2
3. Upload the files in this package to that branch, replacing files with the same names.
4. Do not delete prasad_picture.JPG from the branch; it is inherited from main.

Switching the public website
----------------------------
In GitHub:
Settings -> Pages -> Build and deployment -> Branch

Choose:
- `main` for Updated Website — Version 1
- `updated-website-version2` for Updated Website — Version 2

Select /(root), save, and allow GitHub Pages a short time to redeploy.

No scientific/website content was intentionally rewritten for Version 2.
The changes are presentation-focused.
